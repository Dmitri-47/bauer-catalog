# BAUER — как создать своего Telegram-бота с каталогом: инструкция для новичка

**Для кого:** для владельца каталога Bauer, который раньше не создавал ботов. Запуск состоит из трёх частей: **Telegram** (бот), **GitHub Pages** (страница каталога) и **Railway** (программа, которая получает и пересылает заявки). Настройка и использование не требуют программирования.

**Что подготовлено:** в этой папке уже лежат сайт `docs/index.html` с фотографиями, `bot.py` для получения запросов, а также редактор и исходные данные в `tools/`. **Бот ещё не создан в Telegram, сайт ещё не опубликован и программа не запущена.** Эти действия выполняет владелец в своих аккаунтах.

> **Безопасность.** Токен — это пароль бота. Никогда не отправляйте его в переписку или третьим лицам, не публикуйте в GitHub, в HTML и на скриншотах. Вводите токен **только** в закрытую переменную `BOT_TOKEN` на Railway. Значения в `.env.example` вымышленные и служат примером.

## 0. Какие файлы здесь есть

- `docs/index.html` — каталог для покупателей, это единственная веб-страница, которую публикует GitHub Pages.
- `bot.py` — программа для кнопки каталога и пересылки заявок вам.
- `tools/update.html` — редактор для обновления каталога вручную.
- `tools/ostatki.csv` — исходные данные по складу на 13.11.2026.
- `tools/template.html`, `tools/build_catalog.py` — шаблон и запасной способ собрать новый каталог.
- `tools/PHOTO_SOURCES.txt` — список источников иллюстраций.
- `.gitignore` — защита от случайной загрузки `.env` в GitHub; **токен всё равно нельзя копировать в файлы**.

## 1. Создайте Telegram-бота в @BotFather

1. В Telegram откройте **https://t.me/BotFather**. Убедитесь, что это официальный бот Telegram с username `@BotFather`.
2. Нажмите **Start / Запустить**, отправьте `/newbot`.
3. В ответ на просьбу о **name** введите отображаемое название, например `BAUER | Каталог экипировки`.
4. В ответ на просьбу о **username** введите свободный латинский адрес, который заканчивается на `bot`, например `bauer_hockey_catalog_bot`. Если занят — придумайте другой. Латинские буквы, цифры, подчёркивание; длина от 5 до 32 символов.
5. BotFather выдаст **токен** и ссылку `https://t.me/ваш_username`. **Сохраните токен в менеджере паролей**, не присылайте его в чат.
6. Не ждите ответа от нового бота прямо сейчас: мы пока не подключили программу к Telegram.

**По желанию — оформление бота.** В `@BotFather` можно выбрать `/setdescription`, `/setabouttext`, `/setuserpic`. Текст описания: «Каталог хоккейной экипировки BAUER из Китая. Выбирайте модель и размер, отправляйте запрос — наличие и стоимость уточняем у поставщика». Это не магазин с гарантированными остатками.

## 2. Опубликуйте каталог через GitHub Pages

1. На компьютере распакуйте ZIP-архив. У вас должна получиться папка, где **сразу** находятся `bot.py` и папка `docs`.
2. Зарегистрируйтесь на **https://github.com** (нужна подтверждённая почта).
3. Нажмите **New repository** (`+` → **New repository**). Назовите репозиторий `bauer-catalog`, выберите **Public**. Создайте его. Данные каталога будут видны всем, что нормально для публичного прайса; секреты туда не помещайте.
4. В открытом репозитории нажмите **Add file → Upload files**. Перетащите **содержимое распакованной папки** (файл `bot.py` и папки `docs`, `tools`, а также инструкцию) — не сам ZIP. Проверьте, что на GitHub файл действительно расположен по пути **`docs/index.html`**, а `bot.py` — в корне репозитория. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В **Build and deployment → Source** выберите **Deploy from a branch**; в **Branch** выберите **main** и **/docs**; нажмите **Save**.
6. В разделе **Pages** появится ссылка на сайт. Обычно это `https://ВАШ_ЛОГИН.github.io/bauer-catalog/` (если репозиторий называется именно `bauer-catalog`). Откройте её с телефона и убедитесь, что видны товары.

**Важно:** сайт открывается публично, но **заявки через Telegram ещё не заработают** до запуска программы из шага 3.

Если GitHub пишет `404`, проверьте, что Pages использует папку `/docs`, есть файл `docs/index.html`, а публикация завершилась (проверяется в **Actions / Pages**).

## 3. Включите программу бота через Railway

1. Откройте **https://railway.com**, зарегистрируйтесь через GitHub и при необходимости разрешите доступ к созданному репозиторию.
2. Нажмите **New Project → Deploy from GitHub Repo**, выберите `bauer-catalog`.
3. Откройте созданный **service** → вкладка **Settings**. Установите **Start Command**: `python bot.py`. Сторонних библиотек программе не нужно. **Домен для Railway НЕ нужен**, программа сама опрашивает Telegram. Если есть настройка числа реплик, оставьте **1** (иначе будут конфликты запросов).
4. Во вкладке **Variables** добавьте три переменные (каждую отдельно):
   - `BOT_TOKEN`: секретный токен из @BotFather (вставить только сюда).
   - `MINIAPP_URL`: точная ссылка из GitHub Pages, начиная с `https://`.
   - `ADMIN_CHAT_ID`: пока поставьте `0` — номер узнаем на следующем шаге.
5. Примените изменения и запустите/перезапустите **Deploy**. На странице **Deployments → Logs** найдите `Бот BAUER запущен`. Если вместо этого ошибка о недостающих переменных, исправьте Variables и разверните заново.
6. **Стоимость:** GitHub Pages в публичном репозитории можно использовать бесплатно. Railway предоставляет пробный доступ и ограниченный бесплатный тариф, но для непрерывной работы может потребоваться платный тариф. Перед запуском проверьте его текущие лимиты и расходы в аккаунте. Программа потребляет ресурсы, пока работает.

## 4. Подключите уведомления лично себе (chat ID)

1. В Telegram откройте вашего нового бота, нажмите **Start / Запустить**. Если сервис Railway работает, он пришлёт сообщение и кнопку `🏒 Открыть каталог BAUER` под строкой ввода.
2. В том же чате напишите `/myid`. Бот ответит: `Ваш Telegram chat ID: ...` (цифры).
3. Скопируйте **только цифры**. Это ID вашего личного диалога в Telegram, его можно использовать для доставки заявок. Не используйте ID чата другого человека.
4. В Railway откройте сервис → **Variables** → замените `ADMIN_CHAT_ID=0` на ваши цифры. Примените изменения / Deploy заново.
5. Вернитесь в Telegram, снова отправьте `/start` и нажмите кнопку `🏒 Открыть каталог BAUER`.

**Почему через `/myid`?** Не нужен посторонний бот для определения ID и не нужно открывать секретный токен в адресной строке браузера.

## 5. Проверьте первый запрос (обязательно)

1. Откройте вашего бота в Telegram, нажмите `/start`.
2. Нажмите **кнопку под строкой ввода**, выберите товар и конкретный размер/вариант.
3. Нажмите **«Мой запрос» → «Отправить запрос на проверку»**.
4. **В ваш личный Telegram** должно прийти сообщение со списком, ценами по файлу, размерами, SKU и данными клиента. Покупателю бот подтвердит, что запрос передан на проверку.
5. Проверьте с аккаунта друга — тогда увидите, как выглядит настоящая заявка от клиента.

**Важное ограничение текущей версии:** отправка заявки через `sendData` работает при запуске из **кнопки клавиатуры, которую отправляет бот**. Если каталог открыть прямой ссылкой, через кнопку меню профиля или как Main Mini App, передача заявки может не работать — в каталоге предусмотрена кнопка **«Скопировать текст запроса»**. Поэтому **пока не включайте отдельную Main Mini App / кнопку меню в @BotFather для приёма заявок**. Если потребуется запуск именно оттуда, код обмена заявками можно изменить позднее.

## 6. Что показывать людям

Делитесь **ссылкой на бота**, а не на техническую страницу GitHub: `https://t.me/ваш_username`.

Текст для Instagram / сообщений: «Подготовил каталог оригинальной хоккейной экипировки BAUER из Китая. Внутри можно посмотреть модели, размеры и ориентировочные цены по последнему прайсу. Выберите нужное и отправьте запрос — наличие проверю у менеджера склада перед подтверждением. Ссылка на каталог: https://t.me/ваш_username».

При общении с покупателями никогда не обещайте, что позиция точно есть на чужом складе; в приложении указан снимок данных от **13.11.2026**.

## 7. Как обновлять прайс раз в неделю

1. Получите от менеджера новые Excel-файлы; отправьте их в ChatGPT с фразой: «Обнови мой BAUER Mini App из этих прайсов. Сохрани прежний дизайн и фотографии, обнови размеры, цены, количество и дату. Непонятные цены не выдумывай».
2. Вы получите **новый файл `index.html`**. Сохраните его на компьютере.
3. Откройте свой GitHub → репозиторий `bauer-catalog` → папку **`docs`** → **Add file → Upload files** → загрузите новый **`index.html`** на замену старого → **Commit changes**.
4. Откройте ту же ссылку GitHub Pages и убедитесь, что дата и цены поменялись. Бота и Railway **перенастраивать не нужно**: ссылка неизменна. Если Telegram держит старую версию, закройте и откройте приложение заново.
5. В рамках этой схемы **ручная проверка у менеджера после каждого запроса обязательна**: каталог отображает остатки на дату обновления, без резервирования и синхронизации.

Самостоятельная альтернатива: открыть `tools/update.html` → выбрать текущий файл `docs/index.html` + новый русскоязычный CSV с той же структурой столбцов → сохранить новый `index.html` и загрузить его в `docs` на GitHub. **Исходные Excel напрямую в редактор не загрузить**, их предварительно нужно привести к русскому CSV; с этим могу помочь я.

## 8. Если что-то не работает

- **Бот создан, но молчит после /start:** BotFather создаёт только аккаунт, а не программу. Проверьте Railway → Logs, переменные `BOT_TOKEN` и `MINIAPP_URL` и статус Deploy.
- **Бот показывает каталог, но заявки не приходят:** проверьте `ADMIN_CHAT_ID`, запущен ли Railway, и открывали ли вы приложение именно по **нижней кнопке бота** после `/start`.
- **Ничего не открывается по ссылке сайта:** проверьте `Settings → Pages`, ветку `main`, папку `/docs`, адрес и публикацию.
- **Фотографии не видны:** часть иллюстраций загружается с внешних сайтов и может блокироваться. Это проблема ссылок, не складского наличия. Для регулярной работы лучше использовать официальные фото с разрешением на публикацию.
- **Заявки приходят дважды либо бот работает нестабильно:** должен работать только **один** экземпляр `bot.py` на один токен; не запускайте одновременно второй локально.
- **В прайсе нет цены:** каталог показывает «Цена уточняется», не подставляя цену.
